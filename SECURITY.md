# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential.
Use GitHub's **Security** tab to submit a private vulnerability report to the
repository maintainers. Include reproduction steps, affected versions, impact,
and any suggested mitigation.

Maintainers should acknowledge reports within three business days. A remediation
timeline will be provided after triage. Never test against production data or
systems without written authorization.

## Supported versions

Only the latest commit on the staging branch and the current production release
receive security fixes.
